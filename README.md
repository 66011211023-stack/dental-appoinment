# DentiCare — PHP + HTML + MySQL Docker

ระบบต้นแบบโครงงานจบคลินิกทันตกรรม เขียนด้วย PHP แบบแยกไฟล์ มี HTML Preview และใช้ MySQL ที่รันด้วย Docker โดยหน้าเข้าสู่ระบบ แดชบอร์ด เมนู และหน้าของผู้ใช้งานทั้ง 4 กลุ่มใช้โครงสร้างและธีมสีกรม–ขาวเดียวกับระบบ Browser ล่าสุด

ไฟล์ `public/assets/css/browser-latest.css` นำชุดรูปแบบจากเว็บไซต์ตัวอย่างล่าสุดมาใช้ตรงกัน ส่วน `php-compat.css` มีไว้รองรับแท็ก `<a>`, `<form>` และ `<details>` ของ PHP โดยไม่เปลี่ยนหน้าตาหลัก สำหรับคำอธิบายโค้ดและหน้าที่ของแต่ละส่วนแบบละเอียดให้อ่าน `CODE_EXPLANATION.md`

ดูตารางเทียบทุกหน้าของเว็บไซต์ต้นแบบกับไฟล์ PHP ได้ใน `SCREEN_MAPPING.md`

## เริ่มต้นบน Windows

1. เปิด Docker Desktop และรอจน Docker Engine ทำงาน
2. เปิด Command Prompt
3. เข้าโฟลเดอร์โครงการ เช่น `cd C:\dental-php`
4. รัน `docker compose up -d --build`
5. เปิด `http://localhost:8080`

เปิด phpMyAdmin ได้ที่ `http://localhost:8081` โดยใช้ `dental_user` / `dental_pass`

## ฟังก์ชันที่เชื่อมฐานข้อมูลแล้ว

- Dashboard และรายงานอ่านค่าจริงจาก MySQL
- ผู้ป่วย: เพิ่มข้อมูลและบันทึกประวัติสุขภาพ
- นัดหมาย: สร้าง อนุมัติ เปลี่ยนสถานะ และจองจากบัญชีผู้ป่วย
- ตารางทันตแพทย์: เพิ่มช่วงเวลาปฏิบัติงาน
- การรักษา: บันทึกวินิจฉัย หัตถการ ตำแหน่งฟัน ค่าใช้จ่าย และปิดนัดหมาย
- วัสดุ: เพิ่ม รับเข้า เบิกออก ตรวจจำนวนคงเหลือ และป้องกันสต็อกติดลบ
- ผู้ใช้: เพิ่มบัญชีตามบทบาทและเปิดหรือปิดบัญชี
- สิทธิ์รักษา: เพิ่ม แก้ไข และเปิดหรือปิดสิทธิ์
- ผู้ป่วยดูประวัติ การแจ้งเตือน และแก้ไขโปรไฟล์ได้
- ทุกฟอร์มที่เปลี่ยนข้อมูลตรวจ CSRF และตรวจบทบาทผู้ใช้งาน

หากแก้ไข `database/init.sql` และต้องการสร้างฐานข้อมูลใหม่ ให้รัน:

```bash
docker compose down -v
docker compose up -d --build
```

## บัญชีทดลอง

| กลุ่ม | Username | Password |
|---|---|---|
| ผู้ดูแลระบบ | admin | 1234 |

ระบบจะอ่านบทบาทจากตาราง `users` และแสดงเมนูตามสิทธิ์โดยอัตโนมัติ ปุ่มออกจากระบบอยู่ในเมนูชื่อผู้ใช้มุมขวาบน

## HTML Preview

เปิด `html/login.html` ด้วยเบราว์เซอร์โดยตรงได้ โดยไม่ต้องใช้ PHP หรือฐานข้อมูล หน้า HTML เชื่อมถึงหน้าตัวอย่างอื่นผ่านลิงก์

## โครงสร้าง

- `public/index.php` จุดรับคำขอและ Router
- `app/Core` การเชื่อมต่อฐานข้อมูล การยืนยันตัวตน และ View
- `app/Views` หน้า PHP แยกตามส่วน
- `app/Views/modules` หน้าจอแต่ละเมนูแยกคนละไฟล์
- `public/assets/css/browser-latest.css` CSS หลักจากเว็บไซต์ตัวอย่าง
- `public/assets/css/php-compat.css` ตัวเชื่อมรูปแบบระหว่างหน้า Browser กับ PHP
- `database/init.sql` โครงสร้างตารางและข้อมูลเริ่มต้น
- `html` หน้า HTML Preview
- `docker-compose.yml` PHP Apache และ MySQL

## กรณีพบ DB_HOST=db ไม่เจอ

ชื่อ host `db` ใช้ได้เฉพาะเมื่อ PHP รันอยู่ใน Docker Compose เดียวกัน หากเปิด PHP ด้วย XAMPP ให้ใช้ `127.0.0.1` และ port `3307` ตาม `config/config.php`
